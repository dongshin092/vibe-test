# PRD: 로또 번호 생성기 (app_lotto)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제품명 | 로또 번호 생성기 |
| 목적 | 버튼 한 번으로 로또 번호 5세트를 생성하고, 고정 번호·제외 번호를 지정해 원하는 조합을 만든다 |
| 대상 | 로또 번호를 빠르게 뽑고 싶은 일반 사용자 (PC / 모바일) |
| 기술 스택 | HTML5, CSS3, Vanilla JavaScript (ES6+), Bootstrap 5.3 (CDN), Bootstrap Icons (CDN) |
| 범위 제외 | 지난 회차 당첨번호 조회, 서버/DB, 로그인, 생성 기록 저장 |

## 2. 파일 구조

HTML / CSS / JS는 반드시 분리한다. 빌드 도구·npm 패키지는 사용하지 않는다.

```
lotto/
├── index.html      # 마크업만 (인라인 style/script 금지)
├── css/
│   └── style.css   # Bootstrap 위에 덮어쓰는 커스텀 스타일
└── js/
    └── app.js      # 상태 관리, 번호 생성, 이벤트 처리, 복사
```

- CDN
  - Bootstrap CSS: `https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css`
  - Bootstrap JS bundle: `https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js`
  - Bootstrap Icons: `https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css`
- `<script src="js/app.js" defer>` 로 로드한다.

### ① 헤더
- 좌측: 클로버 아이콘 박스 (`bi-clover`, 44×44, 노란 배경 `#FAC775`, 둥근 모서리 12px)
- 제목: "로또 번호 생성기" (20px, 굵게)
- 부제: "고정할 번호와 뺄 번호를 고르고 생성을 눌러보세요" (13px, 회색)

### ② 분할 선택판 (고정 / 제외)
- Bootstrap 그리드: `row g-3` > `col-12 col-md-6` 두 개
  - 768px 이상: 좌(고정) / 우(제외) 2분할
  - 768px 미만: 위(고정) / 아래(제외) 세로 배치
- 각 패널은 카드 (`card`, 흰 배경, 얇은 테두리, 둥근 모서리 12px)
- 패널 헤더
  - 고정: `bi-pin-angle` 파란 아이콘 + "고정 번호" + 카운트 배지 `0 / 5` (파란 연한 배경)
  - 제외: `bi-slash-circle` 빨간 아이콘 + "제외 번호" + 카운트 배지 `0 / 39` (빨간 연한 배경)
- 번호 그리드: CSS Grid 7열 (`grid-template-columns: repeat(7, 1fr)`, gap 5px), 1~45 원형 버튼 (`aspect-ratio: 1`)
- 패널 하단: 좌측 안내문(고정: "모든 세트에 포함", 제외: "생성에서 제외"), 우측 "초기화" 링크 버튼 (`bi-arrow-clockwise`)

### ③ 액션 버튼
- "번호 생성하기 (5세트)" — 주 버튼 (`btn btn-primary`, 높이 50px, 남은 폭 전부 차지, `bi-stars` 아이콘)
- "전체 초기화" — 보조 버튼 (`btn btn-outline-secondary`, 높이 50px, `bi-arrow-counterclockwise` 아이콘)
- 버튼 아래 에러 메시지 영역 (빨간 13px 텍스트, 평소 비어 있음)

### ④ 생성 결과
- 카드 헤더: "생성 결과" + 우측에 "전체 복사"(`bi-copy`), "결과 초기화"(`bi-trash`, 빨간색)
- 빈 상태: "생성 버튼을 누르면 5세트가 여기에 나와요" (가운데 정렬, 연한 회색)
- 결과 행 (A~E, 행 사이 얇은 구분선)
  - 세트 라벨 (24×24 둥근 사각형, A/B/C/D/E)
  - 번호 공 6개 (36×36 원형, 오름차순)
  - 행 오른쪽 끝 "복사" 버튼 (`btn btn-sm btn-outline-secondary`, `ms-auto`)

## 4. 기능 요구사항

### F1. 고정 번호 선택
| ID | 요구사항 |
|---|---|
| F1-1 | 고정 판에서 번호 클릭 시 선택 ↔ 해제 토글 |
| F1-2 | 최대 5개. 5개 상태에서 미선택 번호 클릭 시 무시 (선택되지 않음) |
| F1-3 | 선택 상태: 파란 배경 `#185FA5`, 흰 글자 |
| F1-4 | 카운트 배지 `n / 5` 실시간 갱신 |
| F1-5 | 고정된 번호는 생성되는 5세트 모두에 포함 |

### F2. 제외 번호 선택
| ID | 요구사항 |
|---|---|
| F2-1 | 제외 판에서 번호 클릭 시 선택 ↔ 해제 토글 |
| F2-2 | 최대 39개 (45 − 6). 39개 상태에서 추가 선택 무시 |
| F2-3 | 선택 상태: 연한 빨간 배경 `#FCEBEB`, 빨간 글자 `#A32D2D`, 취소선 |
| F2-4 | 카운트 배지 `n / 39` 실시간 갱신 |
| F2-5 | 제외된 번호는 생성 시 후보에서 빠짐 |

### F3. 고정 ↔ 제외 상호 배타
| ID | 요구사항 |
|---|---|
| F3-1 | 한쪽 판에서 선택된 번호는 반대쪽 판에서 비활성 (투명도 0.3, `cursor: not-allowed`, `disabled`) |
| F3-2 | 비활성 번호 클릭 시 아무 동작 없음 |
| F3-3 | 한쪽에서 해제하면 반대쪽에서 즉시 다시 활성화 |

### F4. 번호 생성
| ID | 요구사항 |
|---|---|
| F4-1 | "번호 생성하기" 클릭 시 5세트(A~E) 생성 |
| F4-2 | 각 세트 = 고정 번호 전부 + 후보 풀에서 무작위로 (6 − 고정 개수)개 |
| F4-3 | 후보 풀 = 1~45 − 고정 번호 − 제외 번호 |
| F4-4 | 세트 내 중복 없음, 오름차순 정렬 |
| F4-5 | 세트 간 중복은 허용하지 않음. 동일 세트가 나오면 다시 뽑는다 (가능한 조합 수가 5 미만이면 중복 허용) |
| F4-6 | 난수는 `crypto.getRandomValues()` 사용 (없으면 `Math.random()` 대체) |
| F4-7 | 후보 풀 개수 < (6 − 고정 개수) 이면 생성하지 않고 에러 메시지: "남은 번호가 부족해요. 제외 번호를 줄여주세요." |
| F4-8 | 다시 생성하면 기존 결과를 새 결과로 교체 |
| F4-9 | 번호 선택을 변경하면 에러 메시지 지움 |

### F5. 결과 표시
| ID | 요구사항 |
|---|---|
| F5-1 | 번호 공 색상은 구간별 (아래 6.2 색상표) |
| F5-2 | 고정 번호에서 온 공은 파란 링으로 강조 (`box-shadow: 0 0 0 2px #fff, 0 0 0 4px #378ADD`) |
| F5-3 | 생성 시 공이 순서대로 튀어나오는 애니메이션 (scale 0 → 1, 공마다 40ms 지연). `prefers-reduced-motion: reduce` 이면 애니메이션 없음 |

### F6. 복사
| ID | 요구사항 |
|---|---|
| F6-1 | **세트별 복사**: 행 오른쪽 "복사" 버튼 → 해당 세트 번호 복사. 형식 `3, 17, 25, 33, 38, 41` |
| F6-2 | **전체 복사**: 결과 헤더 "전체 복사" → 5세트 복사. 형식 (줄바꿈 구분) `A: 3, 17, 25, 33, 38, 41` |
| F6-3 | 복사 성공 시 해당 버튼이 1.5초간 "✓ 복사됨" + 초록 스타일로 바뀌었다가 원래대로 복귀 |
| F6-4 | 결과가 없을 때 "전체 복사"는 아무 동작 없음 |
| F6-5 | `navigator.clipboard.writeText()` 우선, 실패하거나 없으면 숨긴 `textarea` + `document.execCommand('copy')` 대체 |

### F7. 초기화
| ID | 버튼 | 동작 |
|---|---|---|
| F7-1 | 고정 판 "초기화" | 고정 번호만 전부 해제 |
| F7-2 | 제외 판 "초기화" | 제외 번호만 전부 해제 |
| F7-3 | "결과 초기화" | 생성 결과만 비우고 빈 상태 문구 표시 (선택 번호 유지). 확인 창 없음 |
| F7-4 | "전체 초기화" | 고정 + 제외 + 결과 + 에러 메시지 모두 초기화 |

## 5. 상태 및 로직 설계 (js/app.js)

### 5.1 상태
```js
const MAX_FIXED = 5;
const MAX_EXCLUDED = 39;
const SET_COUNT = 5;
const SET_LABELS = ['A', 'B', 'C', 'D', 'E'];

const state = {
  fixed: new Set(),     // 고정 번호
  excluded: new Set(),  // 제외 번호
  results: [],          // number[][] — 생성된 세트
};
```

### 5.2 주요 함수
| 함수 | 역할 |
|---|---|
| `init()` | 두 번호판 버튼 생성, 이벤트 바인딩, 초기 렌더 |
| `toggleFixed(n)` / `toggleExcluded(n)` | 상호 배타·최대 개수 검사 후 토글, `renderBoards()` 호출 |
| `renderBoards()` | 버튼 클래스(`is-fixed`, `is-excluded`, `disabled`)·카운트 배지 갱신 |
| `getPool()` | 후보 풀 배열 반환 |
| `randomInt(max)` | `crypto.getRandomValues` 기반 0 ~ max-1 정수 |
| `generateSet(pool)` | 고정 + 무작위 선택 후 정렬된 6개 배열 반환 |
| `generateAll()` | 검증 → 5세트 생성(세트 간 중복 방지) → `state.results` 저장 → `renderResults()` |
| `renderResults()` | 결과 행·공·세트 복사 버튼 렌더, 빈 상태 처리 |
| `copyText(text, button)` | 클립보드 복사 + 버튼 피드백 |
| `resetFixed()` / `resetExcluded()` / `resetResults()` / `resetAll()` | 초기화 |
| `getBallColorClass(n)` | 구간별 색상 클래스 반환 |

### 5.3 구현 규칙
- 번호판 버튼은 JS에서 1~45 생성 (HTML에 45개 하드코딩 금지). 버튼은 처음 한 번 만들고 이후에는 클래스만 갱신한다.
- 이벤트는 각 번호판 컨테이너에 **이벤트 위임** (`data-number` 속성 사용).
- 결과 행 복사 버튼도 결과 컨테이너에 이벤트 위임 (`data-set-index`).
- 전역 변수 최소화 — 파일 전체를 IIFE 또는 `DOMContentLoaded` 콜백으로 감싼다.
- `innerHTML`에 사용자 입력은 들어가지 않지만, 결과 렌더는 `createElement` 사용을 권장.

## 7. 접근성
- 번호판 버튼: `<button type="button">`, `aria-pressed="true|false"`, `aria-label="고정 7번"` / `"제외 7번"`
- 비활성 버튼은 `disabled` 속성 사용
- 결과 영역: `aria-live="polite"` (생성·초기화 시 스크린리더 안내)
- 에러 메시지: `role="alert"`
- 세트 복사 버튼: `aria-label="A 세트 복사"`
- 색상만으로 상태를 구분하지 않음 (제외 = 취소선, 고정 = 링 강조 병행)

## 8. 비기능 요구사항
- 외부 통신 없음 (CDN 로드 제외). 오프라인에서도 생성 기능 동작 (스타일만 깨질 수 있음)
- 최신 Chrome / Edge / Safari / Firefox 및 모바일 브라우저 지원
- 실행: VS Code Live Server 등 로컬 서버(`http://localhost`) 권장. 클립보드 API는 보안 컨텍스트(https/localhost)에서만 동작하므로 `file://`에서는 F6-5 대체 방식이 사용됨

- [ ] 고정 6번째 선택 시도 → 선택되지 않음, 카운트 `5 / 5` 유지

- [ ] 고정 판에서 10 선택 → 제외 판 10 비활성, 해제 시 다시 활성
- [ ] 제외 39개 선택 후 생성 → 남은 6개로 생성 (모든 세트 동일 허용)
- [ ] 고정 5개 + 제외로 후보 0개 → 에러 메시지 표시, 결과 변화 없음
- [ ] 세트 B 복사 → 클립보드에 `n, n, n, n, n, n` 형식, 버튼 1.5초간 "복사됨"
- [ ] 전체 복사 → `A: ...` ~ `E: ...` 5줄
- [ ] 결과 초기화 → 결과만 비고 선택 번호는 유지
- [ ] 전체 초기화 → 선택·결과·에러 모두 초기화
- [ ] 모바일(375px)에서 선택판 세로 배치, 가로 스크롤 없음
- [ ] 키보드(Tab/Enter/Space)만으로 모든 기능 사용 가능
